ENDPOINT DEVICES OR OS:
THE DEVICES OR OS OTHER THAN THE PRESENT IN THE NETWORK OR NOT PRESENT IN THE NETWORK.
EX: TABS, LAPTOP, COMPUTER, WINDOWS IN THE USER SYSTEM, IOT DEVICES.
ENDPOINT SECURITY:
IT REFERS TO THE PROTECTION OF THE END USER DEVICES FROM CYBERTHREATS. IT INCLUDES TECH AND PRACTICES DESIGN TO PREVENT , DETECT, RESPOND AND RECOVER FROM THE ATTACKS.
ENSURE SECURITY:
1. ANTIVIRUS
2. ENDPOINT DETECTION RESPONDS
3. HOST BASED FIREWALL
4. DATA LOSS PREVENTION
5. APPLICATION CONTROL
6. MOBILE DEVICE MANAGEMENT
7. DISK ENCRYPTION
8. ENDPOINT PRIVELEGE MANAGEMENT
     

OBJECTIVE:
IT'S OBJECTIVE TO SECURE THE AN ENDPOINT DEVICES AGAINST THE THE UNAUTHORIZED ACCESS, MALWARE, AND NETWORKS THREATS BY REDUCING IT ATTACK LAYER
THE MAIN HARDENING TECHNIQUES :
1. ACCESS CONTROL & AUTHENTICATION:
   SHOULD ENFORCE STRONG PASSWORD POLICIES.
   DISABLE ROOT LOGIN VIA SSH
   IMPLEMENT MULTIPLE FACTOR AUTHENTICATION
2. FIREWALL
   CONFIGURE UNCOMPLICATED FIREWALL TO BLOCK ALL THE INCOMING TRAFFIC BY DEFAULT.
3. SERVICE & ENDPOINT MINIMIZATION
   IDENTIFY AND DISABLE UNUSED SERVICES TO ELIMINATE POTENTIAL BACKDOORS.
4. INTRUSION DETECTION SYSTEM
   INSTALL TOOLS MONITORS LOG FILES.

TO HARDEN THE WINDOWS ENDPOINT SECURITY IN THE WINDOWS:
Firewall: Set-NetFirewallProfile -Profile Domain,Public,Private -Enabled True

Disable Insecure Protocol (SMBv1): Disable-WindowsOptionalFeature -Online -FeatureName SMB1Protocol

Enable Antivirus (Defender): Set-MpPreference -DisableRealtimeMonitoring $false

Password Policy: Configure Account Lockout threshold via secpol.msc (Local Security Policy).
TO HARDEN THE LINUX ENDPOINT SECURITY:
ACCOUNT AND ACCESS SECURITY
DISABLE DIRECT ROOT LOGIN: WE NEED TO STOP ATTACKERS FROM HITTING THE SUPERUSER ACCOUNT DIRECTLY OVER THE NETWORK. JUST SET PERMITROOTLOGIN NO IN THE /ETC/SSH/SSHD_CONFIG FILE.
ENFORCE SSH KEYS: PASSWORDS CAN BE BRUTE-FORCED, SO TURN THEM OFF ENTIRELY. SET PASSWORDAUTHENTICATION NO IN THE SAME SSH CONFIG FILE TO ONLY ALLOW SECURE SSH KEYS.
PASSWORD POLICIES: FOR LOCAL ACCOUNTS, MAKE SURE PASSWORDS EXPIRE AND MEET COMPLEXITY RULES USING PAM (/ETC/PAM.D/COMMON-PASSWORD) AND /ETC/LOGIN.DEFS.
LEAST PRIVILEGE: NEVER SHARE THE ROOT PASSWORD. FORCE EVERYONE TO USE SUDO FOR ADMIN TASKS SO WE CAN TRACK WHO DID WHAT.

NETWORK AND BOUNDARY DEFENSE
DEFAULT-DENY FIREWALL: THE RULE OF THUMB IS TO BLOCK EVERYTHING COMING IN BY DEFAULT AND ONLY OPEN EXACTLY WHAT WE NEED. USING UFW, WE RUN:
SUDO UFW DEFAULT DENY INCOMING
SUDO UFW DEFAULT ALLOW OUTGOING
SUDO UFW ALLOW <SPECIFIC-PORT>
KILL UNUSED PROTOCOLS: IF WE ARE NOT USING IPV6, DCCP, SCTP, OR RDS, WE SHOULD DISABLE THEM VIA KERNEL MODULES SO THEY CANNOT BE EXPLOITED.
TWEAK KERNEL NETWORKING (SYSCTL): WE NEED TO STOP IP SPOOFING AND IGNORE ICMP BROADCASTS (PING SWEEPS). ADD THESE RULES TO /ETC/SYSCTL.CONF:
NET.IPV4.TCP_SYNCOOKIES = 1
NET.IPV4.CONF.ALL.ACCEPT_SOURCE_ROUTE = 0
NET.IPV4.CONF.ALL.ACCEPT_REDIRECTS = 0

SERVICE AND ATTACK SURFACE REDUCTION:
TURN OFF UNNECESSARY SERVICES: EVERY RUNNING SERVICE IS A POTENTIAL DOOR IN. FIND WHAT IS NOT NEEDED AND KILL IT:
SUDO SYSTEMCTL STOP <SERVICE-NAME>
SUDO SYSTEMCTL DISABLE <SERVICE-NAME>
AUTOMATE PATCHES: WE DO NOT WANT TO MANUALLY UPDATE EVERYTHING. SET UP UNATTENDED-UPGRADES SO SECURITY PATCHES INSTALL THEMSELVES IN THE BACKGROUND.

INTRUSION PREVENTION AND INTEGRITY MONITORING:
BAN REPEAT OFFENDERS (FAIL2BAN): THIS TOOL WATCHES OUR AUTHENTICATION LOGS. IF AN IP KEEPS FAILING TO LOG IN, FAIL2BAN AUTOMATICALLY DEPLOYS A TEMPORARY BAN AGAINST IT.
SCAN FOR MALWARE: WE SHOULD REGULARLY RUN RKHUNTER OR CHKROOTKIT TO MAKE SURE NO ONE PLANTED A BACKDOOR OR ROOTKIT ON OUR SYSTEM.
MONITOR FILE CHANGES: USE AIDE OR TRIPWIRE. THEY TAKE HASHES OF OUR CRITICAL SYSTEM FILES AND ALERT US IF SOMEONE MODIFIES THEM WITHOUT PERMISSION.

MANDATORY ACCESS CONTROL (MAC) AND STORAGE:
KEEP MAC ENFORCED: ALWAYS LEAVE APPARMOR (ON UBUNTU) OR SELINUX (ON RED HAT) IN ENFORCING MODE. IT KEEPS COMPROMISED SERVICES FROM ACCESSING THINGS THEY SHOULD NOT TOUCH.
LOCK DOWN MOUNT POINTS: TEMPORARY FOLDERS LIKE /TMP OR /DEV/SHM ARE COMMON PLACES FOR ATTACKERS TO DROP MALWARE. EDIT /ETC/FSTAB AND ADD THE NODEV, NOSUID, NOEXEC FLAGS TO THOSE PARTITIONS SO SCRIPTS CANNOT EXECUTE FROM THERE.

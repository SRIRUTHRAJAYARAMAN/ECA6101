# ECA6101
This project focuses on designing and implementing a highly available enterprise VPN architecture using Cisco Packet Tracer. The main objective is to provide secure and continuous communication between the main enterprise network and remote/branch networks even when a network link or router fails. The network uses VPN/IPsec to encrypt communication and protect data from unauthorized access. Multiple routers and communication links are used to create redundant paths, so traffic can use an alternative path when the primary path becomes unavailable. Technologies such as HSRP, redundant routing, and backup WAN links can be used to provide automatic failover. The project is evaluated by first testing communication under normal conditions and then intentionally creating failures, such as disconnecting the primary link or shutting down the primary router. Connectivity is then tested again using tools such as ping and traceroute. If communication continues through the backup path, it proves that the network can maintain secure communication during failures.
